*&---------------------------------------------------------------------*
*& Report ZZTEST_SVA
*&---------------------------------------------------------------------*
*&This custom program is being used to have Custom Fields added for COOIS
*&selection criteria. Currently SAP doesnt not allow any exits on the
*&COOIS screen.
*&9004362378 - Add Zshipdate to COOIS selection screen
*&Sangeeta Vasudeva NTT data 07/30/2026
*&---------------------------------------------------------------------*


REPORT zcoois_wrapper.

TABLES: aufk, ioitem, knvv  .
SELECTION-SCREEN: BEGIN OF BLOCK b1 WITH FRAME TITLE text-001.
  SELECT-OPTIONS:
    s_aufnr FOR aufk-aufnr,
    s_sdate FOR aufk-zzshipdate,
    s_kdauf FOR ioitem-kdauf,
    s_kdpos FOR ioitem-kdpos,
    s_kvgr1 FOR knvv-kvgr1 NO INTERVALS NO-EXTENSION,
    s_prdst FOR aufk-zzuserstat NO INTERVALS.
  PARAMETERS: p_syst1 TYPE tj02t-txt04,
              p_werks TYPE marc-werks.

SELECTION-SCREEN: END OF BLOCK b1.

SELECTION-SCREEN: BEGIN OF BLOCK b2 WITH FRAME TITLE text-002.
  PARAMETERS: p_layout TYPE ppio_entry_sc1100-alv_variant.
SELECTION-SCREEN: END OF BLOCK b2.


START-OF-SELECTION.

  SELECT aufnr
    INTO TABLE @DATA(lt_orders)
    FROM aufk
    WHERE zzshipdate IN @s_sdate
    AND kdauf IN @s_kdauf
    AND kdpos IN @s_kdpos
    AND zzuserstat IN @s_prdst.

  IF lt_orders[] IS INITIAL.
    MESSAGE s000(su) WITH 'No orders found for selection criteria' .
    LEAVE LIST-PROCESSING.
  ENDIF.
  LOOP AT lt_orders INTO DATA(ls_order).

    s_aufnr-sign = 'I'.
    s_aufnr-option = 'EQ'.
    s_aufnr-low = ls_order-aufnr.
    APPEND s_aufnr.

  ENDLOOP.

  SUBMIT ppio_entry
    WITH s_aufnr IN s_aufnr
    WITH p_syst1 = p_syst1
      WITH    p_werks = p_werks
    AND RETURN.

 AT SELECTION-SCREEN ON VALUE-REQUEST FOR  p_layout.

  DATA: ls_variant TYPE disvariant,
        ls_vari    TYPE disvariant.

  ls_variant-report = 'PPIO_ENTRY'.

  CALL FUNCTION 'REUSE_ALV_VARIANT_F4'
    EXPORTING
      is_variant    = ls_variant
      i_save        = 'A'      "A = User + Global variants
    IMPORTING
      es_variant    = ls_vari
    EXCEPTIONS
      not_found     = 1
      program_error = 2
      OTHERS        = 3.

  IF sy-subrc = 0.
    p_layout  = ls_vari-variant.
  ENDIF.
